# MDFolio

MDFolio is a Markdown reader, editor and annotation notebook for iPhone and iPad. Read your own files, keep notes beside their source, and revisit a thought in context.

## Product website

The bilingual product page lives in [`index.html`](index.html). It includes the product overview, getting-started guide, privacy statement and support information in one page. Its screenshots and app icon are in [`assets/`](assets/).

## App

The iOS app source is maintained in the `MDFolio/` directory. It reads local Markdown and projects, supports public GitHub repository imports, and stores document annotations locally alongside the source files.
